# Music-ID 现代化 UI 设计方案

本方案旨在为 `music-id` 项目提供一个现代、直观且用户友好的图形界面，将底层的离线识曲能力转化为易于使用的应用程序。

## 1. 技术栈选择分析

| 框架 | 优势 | 劣势 | 结论 |
| :--- | :--- | :--- | :--- |
| **Streamlit** | 开发速度极快，天然支持数据展示，部署简单（Web）。 | 布局相对固定，交互逻辑较为线性，不适合复杂的桌面应用交互。 | 适合快速原型，但缺乏“软件感”。 |
| **Flet (Flutter for Python)** | **现代化 Material Design 风格，支持跨平台（Web/Desktop），布局灵活，交互流畅。** | 学习曲线略高于 Streamlit，生态相对较小。 | **推荐方案**：能提供最现代的视觉效果和接近原生应用的体验。 |
| **PySide6 + Modern Theme** | 极致的性能和控制力，功能最全，工业级标准。 | 开发周期长，样式定制（QSS）繁琐，界面默认风格陈旧。 | 过于沉重，除非需要极高性能的实时波形显示。 |

**最终建议：选择 Flet**
Flet 允许我们使用 Python 编写具有 Flutter 视觉水准的界面，能够轻松实现圆角、阴影和流畅的动画，非常符合“现代化审美”的要求。

## 2. 界面布局设计

应用采用 **侧边导航栏 + 主内容区** 的经典结构。

### 2.1 导航结构
- `🏠 首页 (Home)`：快速概览，显示当前曲库状态（歌曲总数、索引路径）。
- `📚 曲库管理 (Library)`：管理本地音乐库。
- `🔍 识曲查询 (Query)`：核心功能区。
- `⚙️ 系统配置 (Settings)`：参数调节。

### 2.2 页面详细设计

#### A. 曲库管理页面 (`Library`)
- **顶部控制区**：
    - `目录选择器`：点击打开文件夹选择对话框。
    - `构建按钮`：触发 `build_library`。
    - `强制重建开关`：Toggle 开关，决定是否 `rebuild=True`。
- **进度区域**：
    - `进度条 (Linear Progress)`：实时显示索引构建进度（基于 `tqdm` 的回调）。
    - `状态文本`：例如 "正在处理: song_01.mp3 (45/100)"。
- **曲库列表 (Data Table)**：
    - 列：文件名、时长、最后修改时间、状态（已索引/失败）。
    - 支持搜索过滤。

#### B. 识曲查询页面 (`Query`)
- **输入区 (Input Zone)**：
    - `文件上传区`：支持拖拽 `.mp3`, `.wav` 文件。
    - `录音按钮`：点击开始录音（调用系统麦克风），再次点击停止并识别。
- **结果展示区 (Result Area)**：
    - **主结果卡片 (Top Match Card)**：
        - 歌曲名称（从路径解析）。
        - 置信度得分（Match Score）。
        - `播放按钮`：直接播放该本地文件。
    - **候选列表 (Candidate List)**：
        - 以列表形式展示次优匹配结果，包含相似度百分比。

#### C. 配置页面 (`Settings`)
- **索引设置**：
    - `线程数`：Slider 滑块（1 - 32）。
    - `索引存储路径`：文本框（可编辑）。
- **算法参数 (Advanced)**：
    - `采样率`、`Hop Length` 等（对应 `config.py` 中的参数），使用数字输入框。
- **环境预设**：
    - `快速模式` / `精准模式` 切换。

## 3. 交互流程

**用户路径：从启动到识别**

1. **初始化** $\rightarrow$ 用户启动应用，首页显示当前索引状态。
2. **建库 (首次使用)** $\rightarrow$ 进入 `曲库管理` $\rightarrow$ 选择音乐文件夹 $\rightarrow$ 点击 `构建` $\rightarrow$ 观察进度条 $\rightarrow$ 完成。
3. **识曲** $\rightarrow$ 进入 `识曲查询` $\rightarrow$ 上传一段音频片段或点击录音 $\rightarrow$ 系统调用 `query_library` $\rightarrow$ 界面弹出结果卡片。
4. **验证** $\rightarrow$ 用户点击结果卡片的 `播放` 按钮，确认识别是否正确。

## 4. 视觉风格建议

### 4.1 色调方案 (Dark Theme)
- **背景色**：深灰色/黑色 (`#121212`, `#1E1E1E`)。
- **主色调 (Primary)**：电光紫 (`#BB86FC`) 或 极光蓝 (`#03DAC5`)，用于按钮和激活状态。
- **辅助色**：深灰 (`#2C2C2C`) 用于卡片背景。
- **文字色**：高亮白 (`#FFFFFF`) 和 次要灰 (`#B0B0B0`)。

### 4.2 组件样式
- **圆角 (Border Radius)**：所有卡片和按钮采用 `12px` - `16px` 的大圆角，营造现代感。
- **阴影 (Elevation)**：结果卡片使用轻微的 `z-axis` 阴影，使其在深色背景上具有浮动感。
- **动画 (Animation)**：
    - 页面切换采用淡入淡出 (`Fade Transition`)。
    - 识别结果出现时使用由下而上的滑动进入效果。
    - 按钮点击时的缩放反馈。

## 5. 架构映射 (UI $\rightarrow$ Service)

| UI 操作 | 调用 `service.py` 函数 | 关键参数传递 |
| :--- | :--- | :--- |
| 点击 `构建` | `build_library()` | `library_dir`, `rebuild`, `thread_count` |
| 上传/录音识别 | `query_library()` | `library_dir`, `query_file` |
| 修改配置 | 更新 `config.py` 或 运行时覆盖 | `AUDIO`, `SPECTROGRAM` 等 |
